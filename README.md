# theCaseWork
This project is part of my externship where I contributed to structured testing and validation of theCaseWork application, specifically in making a New Case, adding a task to the homepage, Editing a Template and Insights page. 
I Automated most test cases that I wrote for this project using Javascript within the VS Code environment.

**Link to project:**(https://camilagallegosqa.netlify.app/casework)
**Link to website:**(https://www.thecasework.com/)


## How It's Made:

**Tech used:** JavaScript, VS Code, WebDriverIO, Azure DevOps, Jira

I first wrote almost 100 Test cases in Jira for the four main features of theCaseWork application. Inside the VS code environment, I structured my code using modules and Classes, along with functions to structure my projects.
Within the Azure environment, I was able to communicate with the Head Engineer to report bugs and UI issues in the application. The Automated tests were run using WebdriverIO


## Lessons Learned:

I learned to work together as a team with other fellow QA's and also communicating effectively with the Head Engineer to report bugs and issues with the application along with making UI/UX suggestions. 
Oftentimes, performance was not ideal, but I learned to be patient and work through those temporary issues. I also learned it's important to think the way other people would in looking for errors or even checking performance issues, in other words, think outside the box.
